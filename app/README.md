# ExamBoost 独立软件

这是 ExamBoost 的独立软件包，解压后就是一个本地网页应用，刷题、错题本、间隔复习、AI 出题都能用。学习数据只写在本机，不上传。

## 三步跑起来

需要 Python 3.8 以上，**不需要 pip 装任何依赖**。

```bash
# 1. 解压后进入本目录
cd app

# 2. 部署并启动
bash deploy.sh

# 3. 浏览器会自动打开 http://localhost:3000
```

手机想用的话：手机连上和电脑**同一个 WiFi**，浏览器打开 `deploy.sh` 结束时打印的局域网地址（形如 `http://192.168.x.x:3000`）。在浏览器菜单里选「添加到主屏」，之后从桌面图标进入就是全屏独立窗口。

## 常用参数

```bash
bash deploy.sh --port 8080              # 换端口
bash deploy.sh --data-dir ~/my-study    # 数据放别处，升级程序不会覆盖
bash deploy.sh --no-open                # 不自动开浏览器
```

不想用脚本，直接跑也行：

```bash
python3 server.py --port 3000
```

## 停止 / 重启 / 看日志

```bash
kill $(cat ~/ExamBoost/server.pid)   # 停止
bash deploy.sh                        # 重启（会先停掉旧实例）
tail -f ~/ExamBoost/server.log        # 日志
```

## 第一轮这样点

1. **刷题** → 选个学段和科目，点「抽 5 题」，故意答错一题
2. **错题本** → 刚才那道错题应该在里面，带解析
3. **复习** → 到期复习里也有它；自评「记得/模糊/忘了」，下次间隔会变
4. **首页** → 已答题数、正确率、掌握度条都跟着动了
5. **AI** → 直接问「帮我讲讲申论归纳概括的采分点」
6. **生成** → 粘一段你的笔记或考纲，点「AI 出题」，再点「下载离线刷题包」

第 1-4 步走通，说明学习闭环正常；第 5-6 步走通，说明模型接入正常。

## AI 功能不用配置

程序会自己找能用的模型，按顺序探测、失败自动换下一个：

| 顺序 | 通道 | 要做什么 |
|------|------|----------|
| 1 | 你自己填的服务 | 可选，设置里填 Base URL 就排最前 |
| 2 | 本机 dsh-our-free-model 本地转发 | 装了并开了开关就自动用 |
| 3 | 本机 dsh-our-free-model 独立服务 | 同上 |
| 4 | **Kilo 免费网关** | 什么都不用做，联网就能用 |
| 5 | Pollinations 匿名池 | 备用，同 IP 约 45 秒一次 |

顶栏右侧的紫色小条显示当前生效的是哪一路。显示「AI 未就绪」时，浏览器访问 `http://localhost:3000/api/ai/providers`，会列出每一路的可用性和失败原因。

> **隐私提醒**：匿名免费通道会把请求经过第三方网关，这类服务通常记录 prompt。不要把身份证号、账号密码等敏感内容粘进资料或对话。介意就换成自己的模型服务。

## 数据在哪

全部在 `data/` 目录（或 `--data-dir` 指定的位置），都是 JSON 文本，可以直接备份、拷贝、查看。想整体导出：浏览器访问 `http://localhost:3000/api/export` 下载。

内置题库在 `data_bank/`，只读，升级程序不会覆盖你的学习数据。

## 题目说明

内置 320 题全部标注「模拟原创题」，按考纲编写，**不冒充真题**。想练自己的题：

- 「生成」页粘贴题目 JSON 导入，或
- 让 AI 根据你的资料出题后点「存进我的题库」

之后在刷题页按「来源 = 我的题目」筛选即可。

## 离线刷题包是什么

「生成」页和「模考」页都能下载一个**单个 HTML 文件**：零依赖、双击就开、完全离线。里面自带刷题、背题、错题、SM-2 复习、统计、进度导出导入，答题记录存在浏览器里，关掉再打开还在。可以直接发给同学一起用。

## 出问题先看这里

| 现象 | 处理 |
|------|------|
| 端口被占用 | 脚本会自动改用邻近端口并打印实际端口 |
| 手机打不开局域网地址 | 确认同一 WiFi；电脑防火墙放行；路由器「AP 隔离」要关 |
| AI 显示未就绪 | 看 `/api/ai/providers`，多半是没外网 |
| AI 出题等很久 | 匿名池高峰期排队，10-60 秒正常 |
| 刷新还是旧页面 | 强制刷新 Ctrl+Shift+R |
| 想清空重来 | 设置 → 数据 → 清空学习数据（会二次确认） |
