# 考试信息源清单（Sources）

> ExamBoost 资源中心：接入国内**官方考试平台**（考纲、公告）与**培训机构网站**（资源、资料）。
> 在独立软件「🌐 资源中心」页可浏览、打开、添加自定义信息源。

---

## 一、官方考试平台（公告 / 考纲 / 报名）

| 平台 | 网址 | 覆盖考试 | 说明 |
|------|------|---------|------|
| 国考专题网站 | https://bm.scs.gov.cn/kl2027 | 公务员 | 中央机关及其直属机构考试录用公务员：公告、职位表、报考指南、报名、成绩 |
| 中央机关遴选选调专题 | https://subb.scs.gov.cn/pp/gkweb/core/web/ui/business/home/lxhome.html | 公务员 | 公开遴选、公开选调公告、职位查询、报名、成绩 |
| 研招网 | https://yz.chsi.com.cn/ | 考研 | 中国研究生招生信息网：公告、招生单位、专业目录、考试大纲、报名、调剂 |
| 中国教育考试网（四六级） | https://cet.neea.edu.cn/ | 四六级 | 全国大学英语四、六级考试：报名、安排、成绩 |

## 三、各省人事考试网 / 人社厅（补充）

各省公务员（省考）、事业单位招聘公告由各省级人事考试网 / 人社厅发布，可在资源中心「添加自定义信息源」加入你所在省份的官网。

## 四、使用方式

1. 打开 ExamBoost 独立软件 → 「🌐 资源中心」
2. 按「官方 / 培训机构 / 自定义」筛选
3. 点「打开」跳转到对应网站查公告、考纲、资源
4. 也可「添加自定义信息源」加入你关注的省份或机构
