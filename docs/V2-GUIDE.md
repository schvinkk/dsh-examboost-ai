# ExamBoost v2 保姆级使用指南

> 一句话：**同一套备考内核，四种用法**。你是谁、考什么、有没有资料，工具先问清楚再给内容；你给的每一份资料、AI 出的每一道题，都能追到出处。

---

## 先看这张表：我该用哪个？

| 你的情况 | 用哪个 | 一句话 |
|---|---|---|
| 就想自己部署一个网页/软件，手机上或电脑上打开就用 | **独立软件（app/）** | 最完整，所有功能都在这 |
| 用 dsh-go 手机 App，想直接在原生界面里抽题、看复习 | **dsh-go 插件** | 针对 dsh 深度优化，和网页共用数据 |
| 用 Claude Code / Cursor / Codex / 任何支持 Skill 的 AI 工具 | **Skill** | 把"备考教练"装进你现有的 AI 里 |
| 要把 Skill 发给别人、或离线 Single-file 分发 | **dist/examboost-full.md** | 一个文件就是完整 Skill |

**重要：独立软件和 dsh-go 插件、Skill 共用同一套"行为规范"**（首启画像、三级溯源、FSRS-5 复习）。独立软件和插件还共用同一份学习数据（`data/` 目录），不重复存。

## 一、独立软件（最完整，推荐先试）

### 1.1 手机上部署（Android / proot）

```bash
# 1. 进入 app 目录
cd /sdcard/AI空间/ExamBoost-AI/app

# 2. 启动（默认 3000 端口）
bash deploy.sh

# 3. 看到提示后，手机浏览器打开
#    本机：http://localhost:3000
#    同一 WiFi 的其他设备：http://<手机IP>:3000
```

需要 Python 3（手机 proot 里已有）。零第三方依赖，不用装 pip 包。

**首次打开会先弹出一个 4 步引导**（这是 v2 最重要的变化）：
1. 选身份：小学生 / 中学生 / 高中生 / 大学生 / 考研 / 考公考编 / 考证 / 在职自学
2. 选目标：考什么、学什么（没有就自己写）
3. 填专业、有无资料、目标日期
4. 完成 → 首页按你的情况给推荐

不设置也能用，但工具不知道你要考什么，只能给通用内容。**建议先花 30 秒设置。**

### 1.2 电脑上部署（Windows / macOS / Linux）

```bash
cd ExamBoost-AI/app
python3 server.py            # 或 Windows: python server.py
# 浏览器打开 http://127.0.0.1:3000
```

### 1.3 独立软件能干什么（v2 全功能）

| 底部入口 | 里面有什么 |
|---|---|
| 🏠 首页 | 你的画像、按情况推荐"该做什么"、答题统计、今日建议 |
| 📥 学 | 导入资料（粘贴/传 PDF/Word/图片 OCR）→ 校对 → AI 按资料出题（逐句标出处） |
| ✏️ 练 | 刷题、模考、错题本、FSRS 复习、学习计划、AI 助手（页内切换，不再两套菜单打架） |
| 🌐 资料 | 官方考试平台（已核验）+ 全网检索入口 + 按你目标推荐的资料源 + 收藏 |
| 👤 我的 | 模型接入、我的题库、数据备份、重置 |

## 二、三级溯源：怎么保证不瞎编

这是 v2 针对"没有参考依据"这个投诉做的核心改造。

**AI 出题/讲解时，每句话都标来源：**
- 🟢 来自你的资料 —— 能追到资料第几段，可以逐字核对
- 🟡 AI 补充 —— 资料里没有的公认背景，明确标出来
- ⚠️ AI 生成 —— 资料里完全没有、AI 自己推的，提醒你核对

**规则：**
- 优先用你资料里确凿的内容出题
- 资料外的题标 ⚠️ 且不超过 20%
- 资料里没答案的问题，直接说"资料里没有这部分，建议补充资料"，**不编造标准答案**
- 引用资料原话逐字摘录，不改写后当原文

你在"学"页生成题目后，能看到每道题的标签和出处段落号。

## 三、FSRS-5 复习（比老版 SM-2 更准）

答错的题自动进复习队列。复习时按 4 档评：
- 1 = 忘记 → 明天再来
- 2 = 吃力
- 3 = 良好
- 4 = 轻松

连续答"良好"，间隔约 1→7→32→118→373 天递增；到期时记忆保留率精确约 90%。这是移植 Anki 官方 py-fsrs（MIT）的成熟算法，不是拍脑袋。

## 四、dsh-go 插件（针对 dsh 深度优化）

### 4.1 装哪

`dsh-go-plugin/` 目录。

### 4.2 怎么装

```bash
# 用官方检查器验证（可选）
node /root/.dsh/skills/dsh-go-plugin/kit/bin/check.mjs dsh-go-plugin --load

# 装进当前主机
dsh plugin --profile web add /sdcard/AI空间/ExamBoost-AI/dsh-go-plugin
```

### 4.3 在哪用、能干什么

装好后，在 dsh-go 原生界面里：
- **输入框上方胶囊**：「抽一题」「讲这题」
- **长按 AI 回复**：「记入错题本」
- **底部状态条**：今日复习数 / 错题数 / 正确率
- **3 个面板**：学习看板、错题本、今日复习

插件**直接读独立软件的 `data/` 目录**，两边数据完全一致。所以要先部署独立软件并答过题，插件才有内容显示。

dsh 专属优化：面板用的是 dsh-go 原生卡片/图表组件（不是网页嵌壳），响应快、跟系统主题走。

## 五、Skill（装进任何支持 Skill 的 AI）

### 5.1 装哪

- 多文件版：`skills/examboost/`（含 13 个 references 参考文档）
- 单文件版：`dist/examboost-full.md`（一个文件就是完整内容，方便分发）

### 5.2 怎么装（以 Claude Code 为例，其他工具类似）

```bash
# 方式 A：把整个 skills/examboost 目录放到 AI 工具的 skills 目录
cp -r skills/examboost ~/.claude/skills/

# 方式 B：单文件版，内容贴进 Skill 文件或提示词
cat dist/examboost-full.md
```

### 5.3 在哪用、能干什么

装好后，直接对你现有的 AI 说考试相关的话，比如"我要考行测""帮我分析这份笔记出题"，它会：
1. 先确认你的身份和目标（如果还没说）
2. 按三级溯源处理你的资料
3. 用 FSRS 管理复习、BKT 追踪掌握度

Skill 是**通用形态**：Claude Code、Cursor、Codex、Gemini CLI 等能装 Skill 的都能用。它教 AI 怎么用备考方法，具体资料解析靠 AI 自身能力。

## 七、数据在哪、隐私

- 所有学习数据只在 `app/data/` 目录，**不上传**
- AI 出题会调用免费模型网关（默认 Kilo 匿名网关，无需 Key），你的资料文本会发给模型
- 介意隐私就在"我的 → 模型接入"换成自己的模型服务
- 不要把身份证号、账号密码等敏感信息放进资料

## 八、常见问题

**Q：打开就是刷题，我不想知道身份行不行？**
行。引导可以跳过，但工具不知道你考什么，推荐会是通用的。随时点首页"修改"重新设置。

**Q：我传了 PDF，文字提取错乱怎么办？**
"学"页上传后可以在文本框里直接改，校对完再点"导入"。扫描件（图片型 PDF）需要 OCR，可能要人工核对。

**Q：AI 出的题标了 ⚠️ 是什么意思？**
表示资料里没有、AI 自己编的，请务必自己核对。🟢 才是能追到你资料的。

**Q：插件里看不到数据？**
插件读独立软件的 data 目录。先在网页版部署并答几题，插件就有内容了。数据目录路径可在看板底部看到。

**Q：换设备数据怎么迁移？**
"我的 → 备份下载"导出，到新设备导入。

## 九、两大亮点（首页显眼入口）

### 亮点1：找资料
首页点「🌐 找资料」→ 官方考试平台（已核验可达）+ 全网检索入口，按你的考试目标推荐，每条都带出处能核对。不再让你去别处瞎找。

### 亮点2：做题库（把资料做成网页版刷题软件）
这是本工具最核心的亮点，两个入口都能做：
1. **首页「📦 做题库」**：选择打包范围（全部题 / 只要我的资料题）+ 科目，下载一个单独的 HTML 文件。
2. **「学」页按资料出题后**：点「⬇️ 把题目做成离线刷题网页」，用你自己的资料生成题库。

生成的 HTML：
- **双击就能用**，不需要网络、不需要装任何东西
- **多科可切**：顶部有科目筛选条（行测/考研数学/英语…25 科），点哪个刷哪个
- **进度本地存档**：答题记录存在浏览器 localStorage，下次打开还在
- **完整功能**：刷题、背题、错题本、FSRS 复习、统计、设置，6 个页签
- **可分享**：把 HTML 发给别人，他们打开就是自己的题库（各自独立存档）
- **带出处**：如果你的题是资料生成的，🟢🟡⚠️ 溯源标签和段落号都保留在题库里
