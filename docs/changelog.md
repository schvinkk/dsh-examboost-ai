# 更新日志（Changelog）

## v0.2.1 (2026-11-20)
- **网盘资料检索（📦 网盘搜）上线**：聚合 PanSeek / PanHub / PanSou / 盘小子 等开源网盘搜索服务，覆盖阿里云盘、夸克、百度、115、迅雷等全平台网盘，一键搜索直达公开分享的学习资料
- 支持自建本地网盘搜索服务（Docker 一键部署）
- 网盘资料收藏夹：保存资料链接随时取用
- 资料→刷题闭环：网盘找到的资料可导入生成刷题工具，AI 出题生成离线刷题网页
- 借鉴来源新增 4 个开源网盘搜索项目（CREDITS.md 实名署名）

## v0.2.0 (2026-11-20)
- **综合型核心引擎上线**：一套系统覆盖所有人群与学习阶段
- 通用学习引擎：资料解析、知识点抽取、间隔复习（SM-2）、掌握度（BKT）、错题本、刷题判分、学习计划、进度持久化
- 考试适配层：考公考编（行测/申论/职测/综应/公基/公文/面试/时政/报考）+ 考研 + 四六级
- 场景自动识别：一提考试类型即自动启用对应模块
- 独立软件：Web 界面（仪表盘/刷题/错题本/复习/学习计划）+ REST API
- 手机/平板支持：局域网访问 + PWA + 离线
- 共性与差异分析文档：docs/COMPARISON.md

## v0.1.0 (2026-11-20)
- 初始版本：项目框架搭建
- 三重形态：DSH 插件 + Skill + 独立软件
- 借鉴来源与署名见 CREDITS.md（40 个项目）
