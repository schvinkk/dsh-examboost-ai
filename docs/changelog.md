# 更新日志（Changelog）

## v1.0.0 (2026-11-20)

这一版把项目从「能跑起来的框架」做成「可以直接给人用的工具」。上一版有若干功能是空壳或点了没反应，这一版逐个补实并做了端到端验证。

### 新增

- **内置题库 320 题**（`app/data_bank/`），全部为模拟原创题并带解析：
  - 考公考编 160：行测 90（政治理论、常识、言语、数量、判断、资料分析）、公基 30、申论 20、面试 10、时政 10
  - 考研 / 四六级 / K12 / 职业资格 / 通用 160
  - 每题校验：四选项前缀规范、答案唯一且与解析一致、题干自洽不依赖外部图表
- **AI 零配置**：自动按「本机免费模型转发 → 独立服务 → Kilo 免费网关 → Pollinations 匿名池」顺序探测并回落。Kilo 网关无需凭据、29 个免费模型，实测开箱即用，不再要求用户先部署别的插件
- **限流处理**：识别 402/429 与 Retry-After，登记冷却时间后自动换通道，而不是直接报错
- **模拟考试**：整卷计时、答题卡跳转、交卷统一判分与逐题解析、超时自动交卷
- **离线刷题包重做**：单 HTML 文件内含刷题 / 背题 / 错题 / SM-2 复习 / 统计 / 存档导入导出，支持暗色模式、键盘操作、进度持久化
- **知识点拆解**：把一段资料拆成结构化知识点清单并标出可能考法
- **逐题 AI 讲解**：刷题页一键请求讲解
- **薄弱点定向刷题**：掌握度低于 60% 的科目可单独抽题
- **打卡与连续天数**、分科目正确率、近 7 天答题量统计
- **dsh-go 原生插件**（`dsh-go-plugin/`）：2 个胶囊 + 1 个长按菜单项 + 状态条 + 3 个面板，直接读独立软件的数据文件，通过官方检查器校验
- **备份导出 / 导入**：`/api/export` 下载完整学习数据

### 修复

- **复习页永远是空的**：旧版答题只写错题本、从不生成 SM-2 卡片，`cards.json` 根本不存在。现在答错自动入队，自评后按 SM-2 调整间隔
- **答错不记解析与选项**：错题本现在保存完整题目，可重做、可标记已消灭
- **抽题会重复**：加入近期已出题目排除
- **并发阻塞**：`HTTPServer` 换成 `ThreadingHTTPServer`，AI 长请求不再卡住整个界面
- **改了代码刷新还是旧页面**：Service Worker 从缓存优先改为导航走网络，缓存版本升到 `examboost-v3`
- **`/api/answer` 空答案误判为错**：无标准答案的题改为返回自评提示
- **学习计划只有三行字**：现在给出每周里程碑与具体任务清单
- **手机竖屏导航文字重叠**：改为底部主导航 + 顶部二级标签，10 个以上页面不再挤在一行
- **样式文件是空的**：`static/style.css` 原先只有一行注释，现在是完整移动端样式表，含暗色适配
- **数据文件可被网页直接下载**：`/data/` 路径返回 403，配置文件权限 0600，接口只回显 Key 指纹
- **deploy.sh 不幂等**：加 PID 文件、端口占用检测、`--data-dir` 可把数据放到程序目录外以免升级覆盖，兼容 Android proot（`termux-open-url`）
- **占位假插件**：删除只有 `console.log` 的 `dsh-plugin/` 空壳，换成真正可用的 `dsh-go-plugin/`
