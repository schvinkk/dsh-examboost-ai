# 报考咨询模块（Baokao）

功能设计参考并致谢：
- gongkao-search（gewen1022，MIT）- 专业+省份→可报岗位
- kaogong-skill（KeWang0622，MIT）- 公告解读、资格、选岗

## 功能
1. **公告解读**：读目标公告，核对条件
2. **资格核对**：年龄、学历、专业、户籍、政治面貌
3. **选岗建议**：专业→岗位匹配、竞争难度
4. **流程说明**：报名、笔试、面试、体检、考察、公示

## 使用
- 输入高考/大学专业名称 + 目标省份
- 查询该专业在公务员考试、事业单位、选调生、三支一扶等渠道可报考岗位范围
- 输出结构化分析报告

## 注意
- 数据来源标注清楚（哪年职位表、哪个渠道、数据质量）
- 不预测岗位分数线
- 不索要身份证号、电话或完整家庭资料
- 仅收集判断所需信息
