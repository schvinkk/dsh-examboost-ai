# 时政模块（Shizheng）

功能设计参考并致谢：
- workbuddy-civil-service-exam-prep（bettermen，MIT）- 五大领域素材卡
- kaogong-skill（KeWang0622，MIT）- 时政热点

## 五大领域素材卡（参考 workbuddy-civil-service-exam-prep）
1. **政治**：重大会议、政策文件
2. **经济**：经济数据、改革举措
3. **社会**：民生、社会治理
4. **科技**：前沿科技、创新成果
5. **生态**：环保政策、绿色发展

## 使用方法
- 联网搜索最新政策（有联网能力时）
- 把政策和新闻放回考试情境
- 标注发布日期与来源
- 无联网能力时说明未核验

## 注意
- 不把历史数据说成今年政策
- 不声称已联网或自动更新
