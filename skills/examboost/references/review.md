# 复习与错题模块（Review）

功能设计参考并致谢：
- kaogong-study-tracker（KaguraNanaga，MIT）- 错题自动识别、每日打卡、晚间总结
- daan（wookat，MIT）- 错题本 SM-2 间隔复习
- kaogong-skill（KeWang0622，MIT）- 错题归因、复习卡、阶段复盘
- study-coach（geyadawang-boop，MIT）- FSRS 复习

## 错题自动识别（参考 kaogong-study-tracker）
- 发一张错题截图，调用多模态模型自动提取：
  - 题目完整内容（含图形视觉描述）
  - 所属科目和题型
  - 正确答案
  - 错误原因推测（知识点不会/粗心/时间不够/概念混淆）
  - 知识点标签
- 识别失败时提示手动输入

## 错因归因（参考 kaogong-skill）
- 概念 / 运算 / 表述 / 方法选择 / 审题 五类

## 间隔复习
- SM-2 算法（参考 daan）
- FSRS 算法（参考 study-coach）
- 错题换壳重考，答对销账

## 每日打卡与进度
- 自然语言汇报成绩
- 统计各模块 7 日准确率
- 找出弱项

## 晚间自动总结
- 每天 21:00 主动汇总当天成绩
- 指出最弱模块
- 给一条具体建议

## 导出
- Excel 错题本（题目、图形描述、错误原因、知识点标签、二刷状态）
- 学习卡（可复制，跨对话继续）
