## 🎯 这是什么

**ExamBoost AI** 是一款**综合型** AI 高效备考学习工具，一套系统覆盖所有场景：

- **通用学习引擎**（所有人群都用）：资料解析、知识点抽取、间隔复习、掌握度追踪、错题本、刷题判分、学习计划
- **考试适配层**（按需启用）：考公考编、考研、四六级、期末、证书、任意学科
- **效率增强**：真题分析、薄弱点识别、进度可视化、每日打卡

### 三重形态

| 形态 | 说明 | 谁用 |
|------|------|------|
| 📦 **插件** | 安装到 DSH / Kimi / 豆包等 AI 应用 | 喜欢完整集成的用户 |
| 📄 **Skill** | 下载后发给任何 AI 使用 | 不想装插件的用户 |
| 🖥️ **独立软件** | 让 AI 自动部署成本地应用，内置大模型调用能力 | 想要独立软件体验的用户 |

> 详细共性与差异分析见 [docs/COMPARISON.md](docs/COMPARISON.md)

## ✨ 功能特性

### 🧠 通用学习引擎（所有人群）
- 多格式资料解析（PDF / Word / PPT / Markdown / 图片）
- 知识点自动抽取与结构化
- 间隔重复复习（SM-2 / FSRS）
- 掌握度追踪（BKT 模型）
- 错题本与错因归因
- 刷题判分与解析
- 学习计划（基础→强化→冲刺）
- 进度持久化（跨会话续学）

### 🎯 考公考编
- **行测**：政治理论、常识判断、言语理解、数量关系、判断推理、资料分析
- **申论**：归纳概括、综合分析、提出对策、贯彻执行、文章写作
- **职测**：事业单位职业能力倾向测验
- **综应**：A-E 类分类训练
- **公基**：公共基础知识
- **公文**：文种辨析、行文规则、格式改错
- **面试**：结构化题目、作答点评、参考框架
- **时政**：热点追踪
- **报考**：专业 → 岗位匹配、竞争难度分析

### 🔄 备考效率引擎
- 真题分析与考点权重计算
- 薄弱点智能识别与优先级排序
- 个性化学习路径生成
- 学习进度预测与调整

### 📦 网盘资料检索（资料渠道齐全）
- 一键搜索网盘公开分享的学习资料（真题、课件、课程、笔记等）
- 聚合 PanSeek / PanHub / PanSou / 盘小子 等开源网盘搜索服务，覆盖阿里云盘、夸克、百度、115、迅雷等全平台
- 搜索即直达，支持自建本地搜索服务（Docker 一键部署）
- 网盘资料收藏夹：保存找到的资料链接，随时取用
- 找到资料后可导入「生成刷题工具」，AI 出题生成离线刷题网页

## 🚀 安装与使用

> 📖 **新手必看**：[保姆级教程](docs/GUIDE.md) - 每个文件在哪用、怎么用，一步步照做就行。

### 方式一：DSH 插件（DeepSeek Harness）

```bash
dsh plugin --profile web add github:yourname/dsh-examboost-ai
```

装完重启 DSH，即可在侧边栏 / 对话中使用。

### 方式二：Skill 直接使用（所有 AI 应用）

复制 [`dist/examboost-full.md`](dist/examboost-full.md) 的内容，发给你的 AI（DSH、Kimi、豆包、通义千问、Claude Code 等），加一句：

> 请按这些规则辅导我备考

### 方式三：独立软件部署

对你的 AI 说：

> 帮我把 ExamBoost 部署到本地

AI 会自动执行部署脚本，启动本地服务，浏览器自动打开，像独立软件一样使用。

**手机/平板也能用！** 手机连接到同一 WiFi，浏览器打开 `http://电脑IP:3000` 即可使用（部署完成后会显示手机访问地址）。也可以使用 PWA 功能将 ExamBoost 添加到手机主屏，像独立 App 一样使用。

## 📥 下载与使用速查（选哪个包、怎么用）

> 本仓库是**三合一**仓库，同时包含插件、Skill、独立软件三种形态。**你不需要全部下载**，按下面选一种最适合你的方式即可。三种形态共用同一套核心引擎，功能等价。

| 你想要什么 | 用哪个包 / 目录 | 怎么用 |
|-----------|----------------|--------|
| 在 **DSH / Kimi / 豆包** 等 AI 应用里直接用 | `dsh-plugin/`（插件形态） | 运行 `dsh plugin --profile web add github:yourname/dsh-examboost-ai` 一键安装，重启 AI 应用即可在侧边栏/对话中使用 |
| **不想装插件**，复制一段规则发给任何 AI 用 | `dist/examboost-full.md`（Skill 完整版，单文件，已含全部 references） | 复制全文发给 AI（DSH、Kimi、豆包、通义千问、Claude Code 等），加一句「请按这些规则辅导我备考」 |
| 想要**独立软件**，浏览器/手机像 App 一样用 | `app/`（独立软件形态） | 对 AI 说「帮我把 ExamBoost 部署到本地」，AI 自动执行 `app/deploy.sh`，浏览器自动打开，手机同 WiFi 也能访问 |
| 想**查看完整源码和文档** | 整个仓库 | `git clone` 后按 [docs/GUIDE.md](docs/GUIDE.md) 保姆级教程逐步操作 |

> 怎么选？想省心用插件选插件；想快速试用选 Skill；想要独立界面和本地大模型算力选独立软件。三者核心引擎完全相同，可随时切换。

## 🧱 项目基础与借鉴来源

ExamBoost AI **不是从零原创，也不是简单复制**，而是在一批优秀开源项目的基础上**整合、优化、创新**而成：

- **项目定位**：整合各开源项目优点 + 优化融合 + 创新（离线刷题工具生成器、资源中心、本地大模型算力、全学段万能适配、私教级全程辅助），形成一套覆盖全学段、全科目的综合备考系统。
- **借鉴的插件与 Skill**：本项目共借鉴 **48 个**开源项目，涵盖考公考编、通用学习、刷题/考试、K12 学段、网盘检索等类别。**每个项目的作者与许可证均在 [CREDITS.md](CREDITS.md) 中实名署名**；本项目未复制任何项目源码，仅参考其功能设计与思路，按 MIT 协议发布。
- **技术基础**：后端 Python 3 标准库 `http.server`（无第三方依赖，开箱即用）；前端原生 HTML/CSS/JS（响应式 + PWA）；DSH 插件基于 DeepSeek Harness 插件规范开发。

> 完整署名与许可证见 [CREDITS.md](CREDITS.md)；与同类项目对比见 [docs/COMPARISON.md](docs/COMPARISON.md)。
